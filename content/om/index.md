Jeg hedder **Evgeny Karpov** og er senior software engineer og freelance-konsulent i København. Jeg arbejder med softwareudvikling, DevOps og platform engineering.

Min styrke ligger i krydsfeltet mellem backend-udvikling og driftbar software: jeg forstår både applikationskode, pipelines, cloud-infrastruktur, deployments og de praktiske problemer, der opstår, når systemer skal fungere i rigtige miljøer.

---

## Professionel profil

Jeg har erfaring med:

- .NET, C# og backend-udvikling
- Azure DevOps, CI/CD og release automation
- Kubernetes, Docker, Helm og KEDA
- Cloud-platforme og moderne deployment flows
- Observability, logs, metrics og tracing
- Dokumentation, debugging og teknisk formidling
- AI-assisteret softwareudvikling og automatisering
- Sikkerhed som en del af leverancen: sårbarheder i afhængigheder, secrets og AI-agenter med klare grænser

Jeg interesserer mig især for, hvordan teams kan levere software hurtigere og mere stabilt uden at miste kvalitet, sikkerhed eller forståelse for systemet.

---

## Det kan du hyre mig til

Jeg tager freelance- og kontraktopgaver i Storkøbenhavn, hybrid eller remote. Typiske opgaver:

- Bygge og forbedre CI/CD-pipelines og release-flows i Azure DevOps
- Infrastructure as code med Bicep eller Terraform, så miljøer kan genskabes
- Deployments, autoskalering og fejlsøgning med Docker, Kubernetes og Helm
- .NET-backend: nye features, opgraderinger og legacy, der skal holdes kørende
- Logs, metrics og tracing, så fejl bliver opdaget, før brugerne opdager dem
- Sikkerhed i leverancen: sårbare afhængigheder, secrets og adgang uden langlivede nøgler
- AI i udviklingsarbejdet, med klare grænser for, hvad agenterne må

Jeg hjælper også mindre virksomheder med at få AI i brug. Se [AI-rådgivning og priser](/ai-raadgivning/).

---

## Min tilgang

Jeg tror på klare systemer, god dokumentation og praktisk automatisering. DevOps handler for mig ikke kun om tools, men om at gøre det lettere for udviklere at bygge, teste, deploye og forstå deres software.

Jeg arbejder bedst, når jeg kan kombinere teknisk fordybelse med konkret forbedring: færre manuelle processer, mere synlig drift, bedre pipelines og mere robuste leverancer.
