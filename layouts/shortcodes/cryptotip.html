{{- /* Crypto tip block. Renders each configured address as selectable text plus a QR code generated at build time by Hugo's images.QR (Hugo >= 0.141). Text and QR both derive from the same config value, so the two cannot drift apart. Case handling differs per chain, and the difference matters: Bitcoin - bech32 is case-insensitive (BIP-173), so the payload is uppercased to reach the QR alphanumeric encoding mode (~5.5 bits/char instead of byte mode's 8). Fewer modules, larger squares, more reliable scan. Ethereum - EIP-55 encodes the address checksum in the capitalisation of the hex letters. Uppercasing would destroy the only error detection the address has, so the case is preserved verbatim and the slightly denser QR is accepted as the cost.
